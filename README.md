# VE-ES

Bộ công cụ Python cho dự án Việt hóa VIRCHE EVERMORE và tạo font `.ffu` từ OTF/TTF. Repo không chứa dữ liệu game. Xem [hướng dẫn dự án](AGENTS.md), [các công cụ](tools/README.md) và [tài liệu định dạng font](CLAUDE.md).

Ứng dụng có cửa sổ cho các công cụ nằm trong [`desktop/`](desktop/README.md). Chạy từ mã nguồn bằng `cd desktop`, `npm install`, `npm start`. Hướng dẫn đóng gói và thiết lập Python nằm trong README của ứng dụng.
